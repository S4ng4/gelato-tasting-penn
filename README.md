# Gelato Tasting · University of Pennsylvania

Event material for the gelato tasting with the **University of Pennsylvania — Italian Foods and Cultures** course, hosted at **Gran Caffè L'Aquila**, Philadelphia.

**When:** Tuesday, December 1, 2026 · 2:00–3:00 PM · Upstairs dining room
**Presented by:** Andrea Sangalli, with Maestro Stefano Biasini

## What's inside

A single-page site (`index.html`), adapted from the Gran Caffè L'Aquila Gelato Tour, with the same structure and design:

- **The Tasting Flight** — the four flavors of the vertical tasting, in serving order:
  1. **Sorbetto** — seasonal fruit, dairy-free
  2. **Desire** — Amarena cherries from Modena in a fior di latte base (Lancaster milk)
  3. **Pistacchio** — DOP pistachios from Bronte, Sicily
  4. **Fondente** — 70% dark chocolate
- **How gelato is made** — the production steps: selection, pasteurization, aging, flavoring, churning, hardening & service
- The history of gelato, gelato vs. ice cream vs. sorbetto, awards, and an FAQ (including allergy notes)
